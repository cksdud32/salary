# 월급시계

근무 중 쌓이는 예상 급여를 작은 창으로 실시간 표시하는 Windows 데스크톱 앱입니다.

## 주요 기능

- 다른 프로그램 위에 항상 표시되는 작은 창
- 1초마다 갱신되는 예상 급여
- 숫자가 아래에서 위로 교체되는 롤링 애니메이션
- 시급, 출근·퇴근 시각, 휴게시간 변경
- 일학습병행제 등 주 5일이 아닌 일정에 맞춘 출근 요일 선택
- 가끔 쉬는 금요일처럼 불규칙한 일정은 이번 달 실제 출근 예정일을 직접 입력해 보정
- 설정을 내 컴퓨터에 자동 저장
- 진행률과 퇴근까지 남은 시간 표시
- 오늘 급여와 같은 근무 조건·1초 주기·롤링 애니메이션으로 올라가는 이번 달 누적 예상 급여
- 인터넷이나 별도 서버 없이 실행

> 표시 금액은 참고용 추정치입니다. 월 예상 급여는 설정에서 선택한 출근 요일이 이번 달에 몇 번 있는지 세어 계산합니다. 이번 달 실제 출근 예정일을 입력하면 그 값이 우선 적용됩니다. 공휴일·비콘 기록·인정 근무시간·세금·수당 및 공제 기준에 따라 실제 입금액과 다를 수 있습니다.

## 실행 방법

1. 이 저장소를 다운로드하거나 ZIP으로 받습니다.
2. `launch.cmd`를 더블클릭합니다.
3. 오른쪽 위의 톱니바퀴 버튼에서 근무시간과 시급을 설정합니다.

Windows가 실행 여부를 물으면 내용을 확인한 뒤 실행해 주세요. 별도의 설치 과정은 없습니다.

## 요구 사항

- Windows 10 또는 Windows 11
- Windows PowerShell 5.1
- .NET Framework의 WPF 구성 요소

일반적인 Windows 10/11 환경에는 위 구성 요소가 기본 포함되어 있습니다.

## 파일 구성

- `salary-clock-app.ps1`: 앱 전체 소스
- `launch.cmd`: 더블클릭 실행용 파일
- `.gitignore`: 로컬 설정 및 임시 파일 제외 규칙

## 설정 저장 위치

앱 설정은 저장소가 아니라 아래 사용자 폴더에 저장됩니다.

```text
%LOCALAPPDATA%\SalaryClock\settings.json
```

따라서 저장소를 공유하거나 깃허브에 올려도 개인 시급과 근무 설정은 포함되지 않습니다.

## 개발 및 수정

앱은 PowerShell과 WPF로 작성되어 있습니다. `salary-clock-app.ps1`을 수정한 뒤 `launch.cmd`로 실행하면 됩니다.

PowerShell 스크립트는 한글 표시를 위해 **UTF-8 BOM** 형식을 유지해야 합니다.
